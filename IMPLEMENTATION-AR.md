# Space Cell — التغييرات والتحقق

> يحتفظ هذا الملف بتاريخ تنفيذ الميزات السابقة. أحدث تصميم للرئيسية ودليل Shopify وحالة التحقق موجودة في [SHOPIFY-HOMEPAGE-AR.md](SHOPIFY-HOMEPAGE-AR.md).

تاريخ التنفيذ: 8 سبتمبر 2026. هذه النسخة تكمل إصلاحات الصفحة الرئيسية السابقة داخل المشروع المرفق، دون نشرها على الموقع الحي.

## متابعة التقرير المصوّر

- أُزيل حد أول 20 مجموعة: اكتشاف Showcase يستكمل كل صفحات Shopify، ويمنع الدوران إذا تكرر cursor. اختُبر وجود مجموعات العرض في الصفحة الثانية فقط، وعدّ المنتجات عبر صفحتين لكل مجموعة.
- أُضيفت حالة فتح مضبوطة و`aria-haspopup="menu"` و`aria-expanded` صراحة في زري الماركات والفئات، مع تمييز التركيز بواسطة `focus-within` و`focus-visible`. يتولى Radix الفتح بالأسهم وEnter والإغلاق بـEscape واستعادة التركيز. هذه الوظائف وحالة ARIA كانت موجودة أصلًا داخل Radix؛ عدم رؤيتها مكتوبة على الزر لا يعني غيابها في المتصفح. الفتح التلقائي بمجرد Tab لم يُضف حتى لا يعترض التنقل بين الروابط.
- أُضيف اختبارا Playwright مستقلان لقائمتي الرأس، وصُحح رابط Support المتبقي إلى `/help`.
- ملاحظة أن `gemini-3.6-flash` غير رسمي لا تتطابق مع [قائمة Google الحالية](https://ai.google.dev/gemini-api/docs/models)، التي تعرض هذا الاسم رسميًا. أبقيت النموذج القابل للضبط من البيئة. إتاحته لمفتاح المتجر الفعلي لم تُختبر.
- غياب سياسة Warranty من Storefront ليس خللًا في الاستعلام؛ الصفحة تنتظر نص سياسة الضمان الفعلية وتعرض وسيلة التواصل الحالية.
- لا يزال تشغيل المتصفح والفحص البصري غير منجزين بسبب القيد البيئي الموثق. اختبارات المتصفح المضافة لا تُعد ناجحة بمجرد اكتشافها أو نجاح البناء.

تعتمد قراءة الصفحات على [PageInfo في توثيق Shopify](https://shopify.dev/docs/api/storefront/2026-07/objects/PageInfo)، وأُعيد التحقق من الاستعلام المعدل مقابل المخطط.

النصوص الجديدة متاحة بالعربية والإنجليزية في `i18n.tsx`. واجهات الإضافة الجديدة تستخدم ألوان الثيم، وتبقى استدعاءات AI ومفتاح Storefront في الخادم. جميع واجهات المتصفح الجديدة تستعمل داخل معالجات الأحداث أو التأثيرات. استمر الاحتفاظ بإصلاحات الأيقونات والصور وCSS والتباعد من النسخة السابقة.

أُصلح أيضًا قارئ ردود OpenAI المباشرة: يقرأ عناصر `output` النصية حتى عند وجود استدعاء بحث قبل الرسالة، بدل الاعتماد على حقل `output_text` الاختصاري الخاص ببعض SDKs. هذا السلوك موثق في [دليل توليد النصوص الرسمي](https://developers.openai.com/api/docs/guides/text).

## التحقق الذي تم فعليًا

| الفحص                                             | الحالة                                                                                                                                      |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `pnpm exec tsc --noEmit`                          | ناجح؛ يشمل الآن ملفات اختبارات TypeScript والإعداد.                                                                                         |
| `pnpm run build`                                  | ناجح بعد مجموعات التغييرات، مع توليد مسار Help تلقائيًا.                                                                                    |
| التحقق من استعلامات Shopify الثلاثة الجديدة       | ناجح مقابل مخطط Storefront.                                                                                                                 |
| `pnpm run test:unit`                              | اختبارا قارئ ردود OpenAI ناجحان.                                                                                                            |
| `pnpm run test:ssr`                               | ناجح باستخدام مدخل SSR المبني فعليًا وبيانات Shopify تجريبية.                                                                               |
| `SPACE_CELL_FIXTURE_FALLBACK=1 pnpm run test:ssr` | ناجح عند غياب مجموعات Showcase والسياسات.                                                                                                   |
| حالة تكرار cursor في Showcase                     | ناجحة؛ يتوقف الجلب ويعود العرض البديل دون تعليق الصفحة.                                                                                     |
| `pnpm test:e2e --list`                            | ناجح؛ اكتشاف 14 حالة عبر إعدادَي سطح المكتب والهاتف، تشمل قائمة الهاتف واختبارَي تنقل قوائم الرأس؛ تُتخطى الحالات غير المناسبة لحجم الشاشة. |
| تنفيذ Playwright في متصفح وفحص بصري               | لم يُنجز: خدمة المعاينة بدأت، لكن المتصفح المتاح حظر الوصول إليها. لا توجد نتيجة نجاح مزعومة لتفاعلات المتصفح أو لقطات مقارنة.              |
| فحص الموقع الحي أو إعادة تقييم URLint             | لم يُنفذ؛ النتائج المرفقة تخص النسخة المحلية.                                                                                               |

تفحص اختبارات SSR استجابة 200 للرئيسية والمساعدة والخصوصية والمنتج وSitemap؛ عنوان H1 واحد؛ Hero وشريط فوائد واحد؛ ترتيب Showcase؛ العرض البديل؛ canonical وروابط المساعدة؛ إزالة script وevent handlers وروابط JavaScript من سياسة تجريبية؛ ترويسات HTML وعدم إضافتها إلى XML. لا تنفذ هذه الفحوص طلبات شراء أو عمليات على متجر حي.

## التشغيل وإعداد بيانات Shopify

استخدم Node.js 22+ وpnpm 11.19.0. حُدّث `pnpm-lock.yaml` وحُذف ملف قفل Bun القديم لمنع التثبيت من اعتماد نسختين مختلفتين من التبعيات.

```sh
pnpm install --frozen-lockfile
pnpm exec tsc --noEmit
pnpm run build
pnpm run test:unit
pnpm run test:ssr
SPACE_CELL_FIXTURE_FALLBACK=1 pnpm run test:ssr
SPACE_CELL_FIXTURE_BAD_CURSOR=1 pnpm run test:ssr
pnpm exec playwright install chromium
pnpm run test:e2e
# أو التشغيل التفاعلي:
pnpm run test:e2e:ui
```

تبدأ اختبارات المتصفح خادمًا محليًا ببيانات تجريبية، ولا تعيد استخدام خادم قد يكون متصلًا بمتجر حقيقي. يظل أمر `pnpm run dev` والإنتاج على التكامل الحقيقي. ملفات `e2e` غير مستوردة في التطبيق.

لترتيب مجموعات العرض: أنشئ تعريف metafield على Collections باسم `custom.sort_order` ونوع `number_integer`، وأتح له القراءة عبر Storefront، ثم املأ قيمته في المجموعات المطلوبة. استخدم handles تبدأ بـ `showcase-`، وصورًا وأوصافًا ومنتجات من Shopify. تم رفع القيد بعد مراجعة التقرير المصوّر: تُقرأ الصفحات التالية حتى نهايتها، بما فيها عندما تخلو أول 20 مجموعة من Showcase.

أدخل السياسات الرسمية في إعدادات Shopify لعرض محتواها. لا يوفر Storefront حقل سياسة ضمان مستقلًا، لذلك تستخدم `/warranty` النص البديل. محتوى السياسات المجلوب يُعرض بلغته المنشورة في Shopify؛ تبديل اللغة يترجم واجهة الصفحة والنص البديل. نص About وFAQ مبني على المعلومات التي قدمتها في الطلب.

## ملاحظة النماذج والتقييم

القيمة الحالية `GEMINI_MODEL=gemini-3.6-flash`: تذكر [صفحة Google الرسمية](https://ai.google.dev/gemini-api/docs/deprecations) أن `gemini-2.0-flash` توقف في 1 يونيو 2026 وتوصي بـ3.6 Flash. لذلك لم يُضبط المشروع على نموذج متوقف. يمكن تغيير النموذج من إعدادات الخادم. لم تُختبر مفاتيح AI أو صلاحيات المتجر الحقيقية ولم تُضمّن مفاتيح خاصة في الأرشيف.

تحتفظ النسخة بـ`robots.txt` الذي يسمح بفهرسة الصفحات العامة. تحذير URLint عن منع الزحف يحتاج إعادة فحص الرابط المنشور بعد رفع الإصلاحات، لأن الاستضافة قد تضيف قواعد أو ترويسات مختلفة. لا يمكن استنتاج معالجة كل بنود Compliance وSEO من الدرجات الإجمالية وحدها دون تفاصيل التقرير.
